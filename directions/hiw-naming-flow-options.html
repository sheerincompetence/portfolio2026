Naming hidden things - flow diagram options

Compare three static maps. No hover states, no dimming, no toast. Step 3 is the practice moment; step 5 is the destination.

Option A

Equal steps, typographic emphasis

Every step looks the same except step 3 gets a small "Key step" label and pin-coloured text. Outcome is a conclusion panel (ruled top, no checkmark) - not a notification.

Option B

Trail map with numbered rail

Reads as a linear journey. Numbers on a left rail; step 3's pin marks where this practice sits. Destination terminates the trail - wider, grounded, no inverted colours.

Option C

Field note / ruled column

Matches the depth-notebook tone. One continuous column; step 3 gets a pin left rule only. Outcome reads as a pull conclusion - separated by a double rule, no iconography.

Regardless of option: remove hover/dim interaction from this diagram (is-interactive in how-i-work.js). The stack diagram above can keep hover if useful; this one should read as a static map.
